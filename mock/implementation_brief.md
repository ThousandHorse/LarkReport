# 🚀 LarkReport 実装指示書

## プロジェクト目的
Google Tasks の情報を収集し、このデザインガイドに基づいた HTML を生成・画像化して Slack へ送信する。

## 実装上の重要ルール

### 1. タスクの遅延判定ロジック
- タスクに `due_date`（期限）が設定されており、かつ未完了の場合：
    - `today` - `due_date` を計算し、1日以上の差があれば「〇〇日遅延」バッジを表示。
    - 遅延しているタスクのカード背景は `bg-rose-50`、枠線は `border-rose-100` を適用し、赤色で強調する。

### 2. AI メッセージのフォーマット
- AI（Gemini）からのレスポンスを HTML に埋め込む際、以下のルールを適用する：
    - 改行コード（`\n`）は `<br>` または `<p class="mt-3">` に適切に変換し、読みやすさを確保する。
    - 重要な指摘（特に遅延タスクへの言及）は、`text-rose-600 font-bold` などのクラスを当てて目立たせる。

### 3. ヘッダーの動的アイコン
- 朝レポート：日付の右隣に `sun` アイコンを配置。
- 夜レポート：日付の右隣に `moon` アイコンを配置。
- 余計な英語（Morning Focus など）は含めない。

### 4. 進捗率（夜のみ）
- `(完了タスク数 / 全タスク数) * 100` で算出し、プログレスバーを同期させる。
